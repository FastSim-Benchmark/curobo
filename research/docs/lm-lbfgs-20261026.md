# LM / L-BFGS 运动质量版本（2026-10-26）

本版本建立在 `20133a7` 和本地已验证的运动质量改进上，保存用户已接受的实现。
启用方式仍为 `MotionPlannerCfg.create(..., prefer_smooth_motion=True)`；普通 pose 请求
只约束末端目标，不增加沿途直线或保持约束。默认仍兼容既有调用。

## 相对 `20133a7` 的改动

- LM 的部分局部候选增加起点至候选终点的软路径正则：评价关节插值的 TCP 偏离程度，
  将残差和解析 Jacobian 纳入 LM。保留不带正则的全局候选；存在环境障碍物时关闭
  此直线偏好，保留原端点目标和全局回退。请求参考状态使用稳定 CUDA Graph 缓冲区。
- L-BFGS 的 Torch 与 CUDA 实现统一过滤无效、非正及近退化曲率对；计算出的方向
  非有限或不满足下降条件时回退到缩放梯度，避免不稳定历史产生上升方向。
- IK 和最终轨迹排序综合双手路径、姿态及整体关节运动，改进候选平衡；对明显较差的
  初值允许使用既有完整精修预算。部分轨迹候选失败时，原始初值经重新定时及原生
  可行性验证后可参与恢复，不用未验证初值替代有效解。
- 增加梯度有限差分、全局候选保留、CUDA Graph 状态更新、场景切换、曲率保护、
  候选恢复和平衡排序回归；完善固定请求的对照、诊断及视频导出工具。

保留原生碰撞球、自碰撞、真实关节边界和终点精度。未采用实验中未显示可靠收益的
其他 LM 数值改法，也未增加生产案例 ID 特例。

## 已完成验证

固定 300 次请求，四版本均 271 次成功、29 次未得解。相对修改前版本，本轮双手 TCP
路径均值减少约 0.60%，稳态规划耗时中位数增加约 3.2%。另有 48 次大幅运动补测，
四版本均成功；本轮路径均值减少约 0.49%，规划中位数增加约 3.2%。三个改进版本的
大幅运动数值表现接近，不据此宣称数量级改善。

两组请求均保存完整四分屏回放、来源哈希及失败状态。用户已查看回放并接受整体
效果；这些是运动学回放，未进行物理执行。20% 规划耗时增幅是观察线，超过不自动
淘汰；轨迹执行时长不参与验收，动作自然时可接受约 30% 的运动量浮动。

本地完整数据位于 `runs/deep_solver_20261026_d01/` 和
`runs/large_motion_20261026_a01/`，受 `.gitignore` 排除；本分支不上传机器人资产、
运行时依赖、大量轨迹或视频。
